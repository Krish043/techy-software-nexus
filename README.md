# 🧩 Techy Software – Company Overview & Review Platform

[![Live Preview](https://img.shields.io/badge/Live%20Site-Visit--Now-0aa1ff?style=for-the-badge&logo=render&logoColor=white)](https://techy-front.onrender.com/)

**Techy Software** is a web platform built using the **MERN stack** to showcase a tech company's services, mission, and customer feedback. It combines clean design with a structured layout and interactive elements.

---

## 🚀 Overview

This platform allows users to:

- Learn about a company’s software services
- Explore its mission, key offerings, and impact
- View user reviews dynamically
- Experience a smooth, modern frontend UI

The website is made for tech startups or freelance portfolios aiming to demonstrate services and gather testimonials.

---

## ✨ Features

- 🏢 Company overview with modern layout
- 📝 Customer reviews section (Google Photos-style card UI)
- 📱 Fully responsive and mobile-friendly
- 🎨 Tailwind CSS styling
- 💬 Clean, intuitive frontend

---

## 🛠 Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express (if extended in future)
- **Hosting:** Render
- *(Currently no database; static reviews only, backend not deployed properly)*

---

## 🧪 How to Run Locally

```bash
git clone https://github.com/Krish043/techy-software-nexus.git
cd techy-software-nexus
npm install
npm start
Then visit:
http://localhost:3000
```
